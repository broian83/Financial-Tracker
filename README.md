# Finance Tracker Application

Mulai aplikasi pemantauan keuangan Anda dengan fitur lengkap:

## Fitur Utama
- 📊 **Pencatatan Transaksi** (Pemasukan & Pengeluaran)
- 💰 **Rekap Saldo Real-time**
- 📅 **Riwayat Transaksi Harian**
- 🔍 **Filter Transaksi** (Masuk/Keluar)
- 💾 **Simpan ke LocalStorage** (Tanpa perlu server)

## Cara Menjalankan
1. Buka terminal di direktori proyek
2. Jalankan perintah berikut:
```bash
npm start
```

## Penjelasan Komponen Utama
- `FinanceApp.js`: Komponen utama yang menampilkan UI dan logika transaksi
- `lucide-react`: Ikon UI yang modern dan responsif
- `tailwindcss`: Framework CSS untuk antarmuka yang responsif
- `localStorage`: Menyimpan data transaksi di browser
